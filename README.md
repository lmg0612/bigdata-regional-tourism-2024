# 유동 인구 밀집 데이터를 활용한 Smart & Green Street

> 제9회 정밀공학 창의경진대회(2024) · 자율 System(빅데이터·인공지능) 분야 · 팀 "거리에서" (2인)

## 개요
공공 쓰레기통 부족과 무단투기 문제를 해결하기 위해, **유동 인구·인구 밀집도·무단투기 데이터**를 분석해 스마트 쓰레기통의 **최적 배치**와 **지역 맞춤 디자인**을 제안하는 연구 아이디어입니다. 관광지 간 콘텐츠 연결성이 관광객 유입과 연관이 깊다는 분석 결과를 배치 전략에 반영했습니다.

## 연구 방법
- **데이터 수집**: 모바일 위치(GPS) 데이터, CCTV·이미지 기반 밀집도, 무단투기 신고 데이터, 공공데이터포털
- **1단계**: 인구 밀집도·유동 인구·쓰레기 발생량·무단투기 패턴 분석 → AI 기반 최적 배치 알고리즘(딥러닝·강화학습)
- **2단계**: 지역 문화와 주민 요구를 반영한 맞춤형 디자인, AI 디자인 생성 모델
- **3단계**: 실증 테스트로 효과 검증 및 개선
- **대상 지역**: 서울 용산구, 전북 전주시

## 기대 효과
쾌적한 도시 환경, 수거·관리 비용 절감, 주민 참여 유도, 스마트 시티 선도 모델
